# Credit Risk Scoring API

A FastAPI service that scores credit applications for default risk, containerized with Docker,
with structured logging (PII-safe) and an automated data drift report.

## What this is

Wraps a scikit-learn RandomForest classifier — trained on the UCI German Credit dataset — behind
a `/predict` endpoint. Every prediction is logged in structured JSON, with the one sensitive
field (marital status/gender) hashed rather than logged in the clear. A separate script produces
an Evidently drift report comparing the training reference data against a simulated production
sample.

## Dataset \& model

UCI Statlog German Credit dataset (1000 applications, 20 features, public domain). RandomForest
classifier in a scikit-learn `Pipeline` (one-hot encoding + passthrough numerics).

**Test set performance:** ROC-AUC 0.79, accuracy 77%

## Setup

```bash
git clone https://github.com/Samay8/credit-risk-service.git
cd credit-risk-service
python -m venv venv
.\\\\venv\\\\Scripts\\\\Activate.ps1        # Windows; source venv/bin/activate on Mac/Linux
python -m pip install -r requirements.txt
```

Train the model (already committed in `model\\\_artifacts/`, but reproducible):

```bash
python train\\\_model.py
```

Run the API locally:

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## Run with Docker

```bash
docker build -t credit-risk-api .
docker run -p 8000:8000 credit-risk-api
```

## PII handling

`personal\\\_status\\\_sex` (marital status + gender) is the one field in this dataset that's sensitive
and identifiable. The model still needs it as a feature, but the structured logs never store the
raw value — only a truncated SHA-256 hash (`personal\\\_status\\\_sex\\\_hash`), so individual applicants
can't be identified from the logs while still allowing repeat-value analysis if needed later.
